# Testimony Subair Portfolio

Static, deploy-ready portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Deploy
Upload the entire `subair-portfolio` folder to Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any static web host. No build command is required.

## Customize
- Edit text/content in `index.html`.
- Adjust colors, spacing and layout in `styles.css`.
- Update interactions in `script.js`.
- Replace `assets/profile.jpg` with the final profile photo if desired.
- Change `hello@example.com` to the real email address.
